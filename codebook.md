# Codebuch des Anne Will Netzwerks

Wir untersuchen ein Netzwerk der Gäste von Anne Will 2022 auf ihre Parteienzugehörigkeit

### edgelist										
from =	Gast. 									
to =	besuchte Show oder Parteimitgliedschaft.   									
relationship =	Gast der Sendung = 1, Parteizugehörigkeit = 2. 									
																			
### nodelist										
id	= Initialien aus dem Anfangsbuchstaben des Vor- und Nachnamens, Organisation oder Sendungsnummer.  									
name =	Vor- und Nachname der Person.  									
sex	= weiblich = 1, männlich =2.  									
type = Person = 1, Organisation = 2.  									
party	= Abkürzung der Partei, Organisation.  									
sector = Berufsfeld.  								
country =	Staatszugehörigkeit.
